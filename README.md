# SnapSpeak

SnapSpeak は、iPhone 向けの語学学習アプリです。読む・聞くだけで終わらせず、**声に出す訓練**を中心に据えます。お手本に合わせて同時に話すシャドーイングと、母語の文を見て（聞いて）即座に学習言語で口頭生産する瞬間英作文（瞬間作文）の 2 つを、同じ教材文の上で回します。

最初のリリースは英語を学ぶ日本人向けです。画面は日本語、出題の母語側（L1）は日本語、学習対象（L2）は英語です。その後、学習対象言語を韓国語・中国語などに広げ、さらに UI の多言語化と母語側の多様化（例: 英語話者が日本語を学ぶ）へ進みます。そのためアプリは「画面の言語」と「学びたい言語のペア」を最初から分けて設計します。学習そのものはオフラインで完結し、録音は既定で端末内に留めます。

対象 OS は iOS 17 以降、UI は SwiftUI、状態管理は MVVM + Repository です。詳細な技術方針と段階的な機能計画は、以下の文書を正本とします。

## コア機能

- **シャドーイング** — お手本音声の変速再生（0.5x〜1.5x）と同時録音、自分の声との聞き比べ、文字起こしに基づく一致度の目安。
- **瞬間英作文** — L1 の文を提示し、制限時間内に L2 で口頭回答。間隔反復（SM-2）で出題し、v1 は複数正解例との照合と自己判定を組み合わせる。
- **共有教材** — Course > Unit > Sentence。1 つの文を両方のモードで使う。訳は言語コード付きで持ち、言語ペアでフィルタする。
