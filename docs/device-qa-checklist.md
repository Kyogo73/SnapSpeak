# 実機 QA チェックリスト

CI（`lint` / `core-linux` / `contentlint` / `ios-macos`）では担保できない項目だけを、[roadmap.md](./roadmap.md) の Phase 1 / Phase 2 DoD から抽出した。実装完了 ≠ DoD 達成。配布前（TestFlight / Store）に本表を埋める。

関連: 音声ポリシーは [architecture.md](./architecture.md) §3、アクセシビリティは architecture §11.5 と [ux-design.md](./ux-design.md) §7 / §10.9、ドライブの補足は [drive-mode-implementation-plan.md](./drive-mode-implementation-plan.md) §4.3。

**前提（全項目共通）**

- 端末: オンデバイス Speech 対応 iPhone、iOS 17+。ロケール `en-US`（L2）。
- シード音声（`Resources/Seed/.../audio/*.m4a`）は現状 **ダミーバイト** で `AVAudioFile` 再生できない。お手本ファイル経路の聴感は本番収録差し替え後。差し替え前のドライブは TTS が本線。
- 合否はチェックボックス。再現条件（機種 / iOS / 経路 / ビルド番号）をメモ欄に残す。
- 参照列の行番号は `docs/roadmap.md` の該当行（2026-08-23 時点の develop）。文言がずれたら見出し「完了基準」側を正とする。

## Phase 1 — CDN（必須）

roadmap Phase 1 DoD「CDN（必須）」L80–L83。実 CDN（Cloudflare R2）と実網が必要。払い出しは [infra-setup.md](./infra-setup.md)。シード音声がダミーバイトのあいだ、取得後の「再生」はレッスン開始・ファイル解決までを確認し、聴感は本番収録差し替え後。

| # | 項目 | 操作 | 期待結果 | 参照 |
|---|------|------|----------|------|
| N1 | マニフェスト取得と checksum | マニフェストから 1 コースをダウンロードする | チェックサム検証に成功し、ローカルに release が残る | L80 |
| N2 | 取得後オフライン再生 | 取得後に通信オフ（機内モード可）で当該コースを開く | 再生・学習ができる。再取得を要求しない | L81 |
| N3 | 更新・削除と失敗時の旧版保持 | 新しい immutable release を選ぶ。別試行で削除。更新を途中失敗させる | 更新と削除ができる。失敗時に旧ローカルを消さない | L82 |
| N4 | CDN 障害時のシード継続 | CDN を到達不能にして初回相当 / 未取得状態で学習する | シードで学習を継続できる。既存ローカルを消さない | L83 |
